### golib26
Утилита-библиотека для взаимодействие с application programming interface of the one famous anonymous imageboard.

#### Как полбзоваться
Запускаем утилиту, и она качает тредикс, либо подписывается на него и обновляет, до тех пор пока он не утонет (с ошибкой 404). Качает в незамысловатом формате, не просто как браузер качает страничку, а более полно и сжато:
* папка с файлами треда (files)
* папка с превьюшками файлов (thumbs)
* джейсон с содержанием треда (текстом постов) формат которого близок к нативной выдаче имейджбоард  

##### Флаги
* b – доска *(по-умолчанию /b/)*
* **t** – нумер треда *(обязательный)*
* p – префикс названия папки для сохранения
* s – подписка на тред, будет сохраняться (обновляться) до выдачи 404
* u – пауза между обновлениями *(по-умолчанию 5 минут)*

##### Примеры
Скачать из раздела /re/ тредец №660911:  
`golib26.exe -b=re -t=660911`  

Скачать из раздела /b/ тредец №660911:  
`golib26.exe -s -t=335566373`  

Скачать из раздела /fag/ тредец №27603889 в директорию «archive»:  
`golib26.exe -b=fag -t=27603889 -d=./archive`
